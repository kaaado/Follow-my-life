# STAGE 20 — PRODUCTION UX & VISUAL HIERARCHY SPECIFICATION

## 1. Primary Information Hierarchy (Home Page)
The user interface follows strict financial UX principles, prioritizing actionable decision support over cluttered metrics.

1. **Hero Balance Card**: Total balance, expandable account breakdown, available vs. reserved sub-balances.
2. **Financial Health Badges**: Safe-to-Spend balance (15% safety buffer subtracted) & Money Coming expected inflows.
3. **Smart Action Center**: Priority-ranked assistant recommendations (e.g. subscription burden alerts, plan feasibility).
4. **Monthly Cash Flow**: Real-time income vs. expense visual ledger with net cash flow indicators.
5. **Recent Activity**: Clean, date-grouped transaction list.

## 2. Progressive Disclosure & Feedback
- Actionable sheets and dialogs state consequences clearly prior to destructive operations.
- Clear empty states with contextual calls-to-action guide users when no transactions, budgets, or plans exist.
